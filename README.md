# Network Traffic Analysis — Packet Capture Investigation

## Overview

A practical network traffic analysis project completed as part of Uneeq Interns training. The repository contains a packet capture, a written analysis report, and a supporting screenshot.

The objective is to examine captured network communications and document observations from the traffic. Refer to the original report for the specific observations and conclusions.

## Project Artifacts

| File | Description |
|---|---|
| `uneeq-task.pcapng` | Packet capture used for traffic analysis |
| `network traffic analysis report.pdf` | Written analysis report |
| `Screenshot 2025-06-11 113347.png` | Supporting screenshot |

## How to Review

1. Download `uneeq-task.pcapng`.
2. Open the capture in Wireshark or another compatible packet-analysis tool.
3. Read `network traffic analysis report.pdf` alongside the capture.
4. Compare the documented observations with the packet data and supporting screenshot.
